How to Enable

Settings → General → Keyboard → Keyboards → Add New Keyboard → Wipe
Then tap Allow Full Access to enable theme sync.

FAQ

The keyboard doesn't appear in my app.
Tap the Globe icon (🌐) on any keyboard to switch to Wipe. If Wipe doesn't appear in the list, go to Settings → General → Keyboard → Keyboards and confirm Wipe is added.
My theme isn't saving.
Make sure you have tapped Allow Full Access in Settings → General → Keyboard → Keyboards → Wipe. Without Full Access, theme preferences cannot be shared between the app and keyboard.
How do I switch themes?
Long-press the ⤺ (undo) key on the keyboard to cycle through all 10 themes. You can also change themes inside the Wipe app.
How does swipe-to-delete work?
Press and hold the ⌫ backspace key, then slide your finger to the left. A preview shows how many characters will be deleted. Lift your finger to confirm the deletion.
How do I use Caps Lock?
Double-tap the Shift key quickly (within 0.4 s) to enable Caps Lock. The key will show ⇪ to indicate it is active. Tap Shift once to turn it off.
Kanji conversion isn't appearing.
Kanji conversion is available in the Japanese flick layout (かな mode). Make sure the keyboard mode is set to かな (not ABC or 123).
The keyboard is too short / too tall.
The keyboard height is fixed at the system standard. If layout looks off, try removing and re-adding the keyboard in Settings.

日本語サポート

有効にする方法

設定 → 一般 → キーボード → キーボードを追加 → Wipe
「フルアクセスを許可」をオンにするとテーマ設定が同期されます。

よくある質問

  • キーボードが出てこない
    🌐（地球儀）ボタンをタップして Wipe に切り替えてください。 設定 → 一般 → キーボード → キーボード でWipeが追加されているか確認してください。
  • テーマが保存されない
    設定 → 一般 → キーボード → Wipe で「フルアクセスを許可」をオンにしてください。
  • テーマの切り替え方
    キーボード上の ⤺ キーを長押しするとテーマが順番に切り替わります。
  • 範囲削除の使い方
    ⌫ を押したまま左にスライドすると削除範囲が表示されます。指を離すと確定削除されます。
  • Caps Lock の使い方
    Shift キーを素早く2回タップするとCaps Lockがオンになります（⇪ 表示）。もう一度 Shift を押すとオフになります。
  • 漢字変換が表示されない
    かなモードでのみ変換候補が表示されます。ABC や 123 モードでは表示されません。
