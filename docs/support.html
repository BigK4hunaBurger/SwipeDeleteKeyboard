How to Enable

Settings → General → Keyboard → Keyboards → Add New Keyboard → Wipe
Then tap Allow Full Access to enable theme sync.

FAQ

The keyboard doesn't appear in my app.
Tap the Globe icon (🌐) on any keyboard to switch to Wipe. If Wipe doesn't appear, go to Settings → General → Keyboard → Keyboards and confirm it is added.
My theme isn't saving.
Make sure you have tapped Allow Full Access in Settings → General → Keyboard → Keyboards → Wipe. Without Full Access, theme preferences cannot sync.
How do I switch themes?
Long-press the ⤺ key on the keyboard to cycle through all 10 themes. You can also change themes inside the Wipe app.
How does swipe-to-delete work?
Press and hold ⌫, then slide your finger left. A preview shows how many characters will be deleted. Lift your finger to confirm.
How do I use Caps Lock?
Double-tap the Shift key quickly (within 0.4 s). The key shows ⇪ when active. Tap Shift once to turn it off.
Kanji conversion isn't appearing.
Kanji conversion is available in かな mode only. Make sure the mode is not set to ABC or 123.
The keyboard layout looks off.
Try removing and re-adding the keyboard in Settings → General → Keyboard → Keyboards.

有効にする方法

設定 → 一般 → キーボード → キーボードを追加 → Wipe
「フルアクセスを許可」をオンにするとテーマ設定が同期されます。

よくある質問

キーボードが出てこない
🌐（地球儀）ボタンをタップして Wipe に切り替えてください。リストに表示されない場合は、設定 → 一般 → キーボード → キーボード で Wipe が追加されているか確認してください。
テーマが保存されない
設定 → 一般 → キーボード → Wipe で「フルアクセスを許可」をオンにしてください。オフの場合、テーマ設定は同期されません。
テーマの切り替え方
キーボード上の ⤺ キーを長押しするとテーマが順番に切り替わります。Wipe アプリ内からも変更できます。
範囲削除の使い方
⌫ を押したまま左にスライドすると削除範囲がプレビュー表示されます。指を離すと確定削除されます。
Caps Lock の使い方
Shift キーを素早く2回タップすると Caps Lock がオンになります（⇪ 表示）。もう一度 Shift を押すとオフになります。
漢字変換が表示されない
漢字変換はかなモードでのみ表示されます。ABC や 123 モードでは表示されません。
キーボードのレイアウトがおかしい
設定 → 一般 → キーボード → キーボード から Wipe を一度削除して再追加してみてください。
